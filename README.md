# Primeiro projeto de Playwright
 - Primeiro projeto de Playwright + Python utilizando apenas:
    - Documentação: https://playwright.dev/python/
    - Guia por IA: Chat GPT, Cursor, GitHub Copilot etc

## Pré-requisito
- Instale versão mais recente do Python

## Configuração de ambiente local

- Python deve estar  instalado

- Preparação de ambiente virtual
    - python -m venv venv
    - Execute um dos dois comandos:
        - source venv/bin/activate
        - venv\Scripts\activate (no Windows)
        
    - pip install pytest playwright
    - playwright install

- Desativando ambiente virtual
    - deactivate
